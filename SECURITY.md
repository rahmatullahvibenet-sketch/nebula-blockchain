# Security policy

NEBULA is experimental, pre-launch software and has had no independent audit. Do not use it with money you cannot lose.

To report a vulnerability privately, use GitHub's **Security -> Report a vulnerability** on this repository.
Please do not open a public issue for a vulnerability that could be used to attack a running network.

I read every report and will answer as soon as I can. I am a single developer, so replies may take a few days.
